## Descripción
ProData es una herramienta en Python para realizar análisis estadísticos, pruebas de hipótesis, intervalos de confianza y estudios de confiabilidad.  
Permite trabajar con una o dos muestras, identificar distribuciones, graficar densidades, funciones de supervivencia y manejar datos censurados.

Tecnologías utilizadas
*Python
*Pandas
*NumPy
*SciPy
*Matplotlib
*Lifelines
*Openpyxl
